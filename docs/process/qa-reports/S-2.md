## Manual checks for the PO (after merge, on https://sabeekhann.github.io/Web-Calculator/)
Do these in each of **Chrome, Edge, Firefox and Safari** (current versions):
1. **Page loads:** open the link. Tip % already shows `0`, and the grey text "Use 0 for no tip." is directly under it.
2. **Tip and total:** click Bill and type `100.00`. Click Tip %, select the 0 and type `15`. Click People and type `3`, then click Calculate. You see "Tip: 15.00", then "Total: 115.00", then "Person 1: 38.34", "Person 2: 38.33", "Person 3: 38.33".
3. **Change the tip:** click Tip %, change 15 to `12.5`. The result disappears straight away. Click Calculate. You see "Tip: 12.50", "Total: 112.50" and three lines of 37.50.
4. **Error shows and clears:** change Tip % to `12.555` and click Calculate. Red text under the grey hint reads "Enter the tip percentage with no more than 2 decimals, for example 12.5." and the box has a red border. Delete the last 5. The red text disappears while you type. Click Calculate. You see "Tip: 12.55", "Total: 112.55", 37.52, 37.52 and 37.51.
5. **Negative tip:** change Tip % to `-5`, click Calculate. The red text reads "The tip can't be negative. Enter a percentage from 0 to 100." and no result is shown.
6. **Keyboard only:** reload the page and don't use the mouse. Tab to Bill, type `50.00`, Tab twice (past Tip %) to People, type `2`, press Enter. You see "Tip: 0.00", "Total: 50.00", 25.00 and 25.00. A clear blue ring shows on each box as you Tab.
7. **375px:** on a phone, or with a very narrow window (Chrome/Edge: F12 → device toolbar → width 375), do step 2 with Bill `1000000.00` and Tip % `100`. You see "Tip: 1,000,000.00" and "Total: 2,000,000.00". Everything is readable and there is no sideways scrolling.
8. **No console errors:** open developer tools (Chrome/Edge/Firefox: F12 → Console; Safari: Settings → Advanced → "Show features for web developers", then Develop → Show JavaScript Console). After steps 1–7 there are no red errors.
9. **Optional (screen reader):** with VoiceOver (Safari) or Narrator (Edge), Tab into Tip %. It is announced as "Tip %" followed by "Use 0 for no tip.".
