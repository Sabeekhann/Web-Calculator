## Build and test evidence
- `npm ci`: OK, 0 vulnerabilities (Node v22.22.0).
- `npm test`: **6 files, 145 tests passed, 0 failed** (vitest 4.1.11). `-t T-S3` runs 20 tests, all passing: unit-logic (5), unit format (5), unit-validation (2), ui-dom (8).

T-S3.5 (format) proves the marker reads the flag and not the amount. Older S-1/S-2 tests use `expectShares`, which matches `^Person n: amount( |$)`. That is why they stay green now that the suffix exists.
- Independent check: `npm run preview` (the built app) driven by Playwright in Chromium (`/opt/pw-browsers/chromium`) at 1280×900 and 375×812. Values were typed key by key, then submitted with Calculate or a real Enter key. 127 page states were checked.

## Manual checks for the PO (after merge, on https://sabeekhann.github.io/Web-Calculator/)
Do these in each of **Chrome, Edge, Firefox and Safari** (current versions):
1. **Page loads:** open the link. Bill, Tip % (showing `0`), People and Calculate are visible.
2. **Marker on the extra cent:** click Bill and type `100.00`. Click Tip %, select the 0 and type `15`. Click People and type `3`, then click Calculate. You see "Person 1: 38.34 (+0.01)", then "Person 2: 38.33" and "Person 3: 38.33" with no "(+0.01)".
3. **No marker when it divides evenly:** change People to `4` and click Calculate. You see four lines of "28.75", and none of them shows "(+0.01)".
4. **Smallest bill:** change Bill to `0.01`, Tip % to `0` and People to `3`, then click Calculate. You see "Person 1: 0.01 (+0.01)", "Person 2: 0.00", "Person 3: 0.00".
5. **Error shows and clears:** change Bill back to `100.00`, Tip % to `15` and People to `0`, then click Calculate. Red text under People reads "Enter the number of people as a whole number from 1 to 100." and no shares are shown. Change People to `3`. The red text disappears as you type. Click Calculate. You see the three lines from step 2.
6. **Keyboard only:** reload the page and don't use the mouse. Tab to Bill and type `120.00`. Tab twice (past Tip %) to People, type `4` and press Enter. You see four lines of "30.00", with no "(+0.01)".
7. **375px, the largest case:** on a phone, or with a very narrow window (Chrome/Edge: F12 → device toolbar → width 375), enter Bill `999999.99`, Tip % `0`, People `100` and Calculate. Scroll down the list. Persons 1–99 read "10,000.00 (+0.01)" and the last line reads "Person 100: 9,999.99". Each line fits on one line and there is no sideways scrolling.
8. **No console errors:** open developer tools (Chrome/Edge/Firefox: F12 → Console; Safari: Settings → Advanced → "Show features for web developers", then Develop → Show JavaScript Console). After steps 1–7 there are no red errors.
