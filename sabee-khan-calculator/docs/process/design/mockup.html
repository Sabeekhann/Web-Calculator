Design mockup: every result state, light and dark

Static picture of the spec in ui-design.md. Each frame stands in for a browser window; its card switches to the wide layout when the frame is at least 600px wide (the app uses the same 600px breakpoint on the viewport).

Pass and Fail always show an icon and the word. Error messages always show an icon and text under the field. The result area keeps the same height in every state.
