# Jobs To Be Done

Each job is written as if no calculator existed: it would make the same sense with a marked paper, a pen and a deadline.

## R-1 Learner

**J-1 (R-1 Learner).** When my hand-marked quiz comes back as raw marks out of a total and the resit deadline is close, I want to know for certain whether I reached the pass mark, even if I missed it by a fraction, so I can decide in time whether to book a resit.

**J-2 (R-1 Learner).** When I find out I fell short of the pass mark, I want to know how many marks I missed it by, so I can judge how much more study I need before I sit the quiz again.

## R-2 Instructor

**J-3 (R-2 Instructor).** When I turn each learner's hand-awarded marks, half marks included, into a score and a pass or fail, I want to judge every learner by the same rule on their exact marks, so I can defend each outcome if a learner challenges it.

**J-4 (R-2 Instructor).** When I tally a learner's marks and make a slip, such as awarding more marks than the quiz allows or leaving the total blank, I want to catch the slip before the outcome goes on record, so I can release scores I never have to correct or retract.

**J-5 (R-2 Instructor).** When I have a whole cohort's papers to work through in one sitting, all marked against the same total and pass mark, I want to get each learner's score and verdict without redoing the parts that never change, so I can finish the cohort in one session and return outcomes promptly.
